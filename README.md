# Alt-Tab

A multi-disciplinary think tank. Part studio. Part lab. Part consultancy.

Alt-Tab works at the intersection of **design, strategy, and technology** —
cross-pollinating ideas across disciplines and applying systems thinking to
complex problems. Based in Nashville, TN.

Find us on Instagram: [@alttab.xyz](https://www.instagram.com/alttab.xyz/)

This repository holds the source for the Alt-Tab website, built with React,
Vite, and Tailwind CSS. Technical setup, project structure, and content/
deployment notes live in [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md).
